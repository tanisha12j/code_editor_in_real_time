# 🧠 Real-Time Code Editor

A collaborative real-time code editor built with **React**, **Express**, **Socket.IO**, and **CodeMirror**. Collaborate with others by sharing a Room ID and edit code together live!

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

---

## 🚀 Features

- ✅ Real-time code editing with multiple users  
- ✅ Unique room creation and joining  
- ✅ Live synchronization across all connected users  
- ✅ Built using React, Express, and Socket.IO  

---

## 🛠️ Tech Stack

- **Frontend:** React, CodeMirror, Socket.IO-client  
- **Backend:** Node.js, Express, Socket.IO  
- **Others:** UUID, CORS
